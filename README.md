# LeadEngine Pro - Setup Guide

## Quick Start (Deploying in 2 Minutes)
1. Unzip `LeadEnginePro_Source.zip`.
2. Upload all 14 files to your web hosting server or free hosting (GitHub Pages, Netlify, Vercel).
3. Open your custom URL in the browser.

## Customization
- **Branding:** Open `index.html` to change the title, logo, and copy.
- **Styling:** Edit `styles.css` to update primary colors to match your brand.
- **API Keys (Optional):** Open `settings.js` to toggle between free Overpass scraping or Google Places API integration.
